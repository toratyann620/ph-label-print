    2. 問い合わせ要求形式について
     要求形式につきましては下記の形式で受け付けます。

     例) リクエスト（ボディ）サンプル
        ①必須項目のみ設定（お問い合せ送り状No 1件）
        {
            "use_type" : "A04",
            "tracking_number" : ["111111111112"]
        }



       ②必須項目のみ設定（お問い合せ送り状No 複数件）
        {
          "use_type" : "A04",
          "tracking_number" : [ "111111111112",
        "222222222223" ]
        }


       ③全項目設定（お問い合せ送り状No 1件）
       {
            "use_type" : "A04",
            "tracking_number" : [ "111111111112" ],
            "detail_flg" : true,
            "history_flg" : true
       }



       ④全項目設定（お問い合せ送り状No 複数件）
       {
         "use_type" : "A04",
         "tracking_number" : [ "111111111112,
       222222222223" ],
         "detail_flg" : true,
         "history_flg" : true
       }
