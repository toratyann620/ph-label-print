# 佐川急便 お荷物問い合わせ API仕様書

> 原典: API連携マニュアル.pdf (2025年12月18日 第5版)  
> 作成: 2026-06-15  

---

## 1. 概要

本APIは、お客様システムから指定のURLへPOSTリクエストを送信することにより、佐川急便で提供しているお荷物の配送ステータス（お荷物問い合わせ情報）をJSON形式で取得できるAPI連携サービスです。

---

## 2. 通信プロトコル・認証情報

### リクエスト情報

| 項目 | 設定値 | 備考 |
|---|---|---|
| **HTTPメソッド** | `POST` | |
| **URL (本番)** | `https://api-service.sagawa-exp.co.jp/api/packages/search/v1` | HTTPSのみ許可 |
| **Content-Type** | `application/json; charset=utf-8` | |
| **Authorization** | `Basic {認証情報}` | 認証情報: `ID + ":" + パスワード` をBase64エンコードした文字列 |

> **Basic認証の例**  
> `ID` が `0192`、`パスワード` が `B54uWQlX6Q6JCZ` の場合：  
> `0192:B54uWQlX6Q6JCZ` をBase64エンコード → `MDE5MjpCNTR1V1FsWDZRNkpDWg==`  
> ヘッダ: `Authorization: Basic MDE5MjpCNTR1V1FsWDZRNkpDWg==`

### アクセス制限・注意事項
* **1TPS（1件1秒）でのアクセス**: 出荷人様（お申込者様）起因の要求でアクセスし配送情報を取得する場合、1秒間に1リクエスト以下の頻度でアクセスしてください。
* **検索可能期間**: お荷物の発送日から **60日間** です。
* **大量アクセス制限**: 不正なお問い合せ送り状Noでの大量アクセス（ALL 0、桁数不正、英数字混在など）はサーバー負荷となるため、アカウントの利用が停止される場合があります。

## 3. リクエストパラメータ (JSONボディ)

リクエストボディはJSONフォーマットで送信します。

| 項目名称 | データ名称 | 型 | 必須 | 備考 |
|---|---|---|---|---|
| 利用種別 | `use_type` | string | **必須** | **固定値: `"A04"`** (第4版より変更) |
| お問い合せ送り状No | `tracking_number` | array(string) | **必須** | 10桁または12桁（ハイフンなし）。複数指定可、**最大10件まで**。 |
| 詳細フラグ | `detail_flg` | boolean | 任意 | `true`：詳細情報を取得する / `false`：取得しない（デフォルト） |
| 履歴フラグ | `history_flg` | boolean | 任意 | `true`：履歴情報を取得する / `false`：取得しない（デフォルト） |

### リクエストサンプル

```json
{
  "use_type" : "A04",
  "tracking_number" : [ "111111111112", "222222222223" ],
  "detail_flg" : true,
  "history_flg" : true
}
```

## 6. エラーレスポンス

結果コードが正常（`0100`）以外の場合のレスポンスイメージです。

### ① パラメータエラー (結果コード: `0199`)

```json
{
  "process_result" : {
    "result_code" : "0199",
    "message" : " Invalid Parameter: use_type[none] "
  }
}
```

#### 主なエラーメッセージと詳細

| エラーメッセージ | エラー詳細 |
|---|---|
| `Invalid Parameter:use_type[none]` | 利用区分が未設定です。 |
| `Invalid Parameter:use_type[invalid]` | 使用できない利用区分が設定されています。 |
| `Invalid Parameter:tracking_number[none]`| お問い合せ送り状Noが未設定です。 |
| `Invalid Parameter:tracking_number[maximum number of tracking_number is 10]` | お問い合せ送り状Noが11件以上設定されています。 |
| `URL not Found` | URLが不正です。 |
| `Internal Server Error: Please contact`| 内部でエラーが発生しています。 |

### ② 認証エラー (結果コード: `99`)

```json
{
  "process_result" : {
    "result_code" : "99",
    "message" : " Authentication Error"
  }
}
```

#### 詳細

* **`Authentication Error`**: `Authorization` のヘッダ値が不正であるか、ID/パスワードに誤りがあります。
